# Aurelia War Mapper ULTRA v5

Telegram-бот для ручной подневной симуляции маппингов. Ты задаешь направление и срок операции линией на карте, бот строит неровное продвижение по дням, узкую серую фронтовую кромку и потом экспортирует всю историю в MP4.

## Что принципиально исправлено

Главное изменение: **родная принадлежность территории и текущий контроль теперь разные слои**.

Раньше бот хранил одно значение «владелец пикселя», поэтому захваченная территория перекрашивалась в родной цвет оккупанта. Это было логически неверно. Теперь:

- `homeland` никогда не меняется
- `control` меняется во время войны
- Кефирстан на родной земле Кефирстана -> `#4A0000`
- Йогуртстан на родной земле Йогуртстана -> `#00134A`
- Кефирстан на земле Йогуртстана -> **`#B12823`**
- Йогуртстан на земле Кефирстана -> **`#1F52A6`**
- оспариваемая территория -> `#707780`

Освобождение автоматически возвращает родной цвет.

## Визуальные слои v4

Встроенная карта войны Йогуртстана теперь использует два исходных слоя из `nado.zip`:

- `ландшафт.png` -> `yogurtstan_terrain.png`
- `точки городов которые нужны на карте.png` -> `yogurtstan_cities.png`

Рендер собирается в таком порядке:

1. исходный серый фон, границы и реки
2. политический контроль
3. физический рельеф, смешанный с политическим цветом только внутри территорий
4. серая фронтовая зона, которая остается плоской и читаемой
5. города и столица поверх всего
6. дата при экспорте MP4

Сила физического слоя по умолчанию `20%`: он показывает рельеф, но не превращает Кефирстан и Йогуртстан в кашу одинакового серого цвета.

`/terrain` заменяет физический слой текущей сессии. `/cities` заменяет слой городов. Оба файла должны иметь точно тот же размер, что и базовая карта. Слой городов должен быть PNG с прозрачным фоном. `/clearterrain` и `/clearcities` удаляют соответствующие слои. `/layers` показывает, что подключено.

Изменение визуальных слоев не меняет историю войны и control-массивы. Поэтому можно прогнать войну, потом заменить физику/города и заново экспортировать MP4 без пересимуляции фронта.

## Палитра

- Родной Кефирстан: `#4A0000`
- Родной Йогуртстан: `#00134A`
- Кефирская оккупация Йогуртстана: `#B12823`
- Йогуртстанская оккупация Кефирстана: `#1F52A6`
- Серая/оспариваемая зона: `#707780`
- Нейтральный фон исходной карты: `#9D9D9D`
- Приказ Кефирстана: `#FF00FF`
- Приказ Йогуртстана: `#00FF66`

`#FFA7A4` считается старым временным цветом старого маппинга и **не принимается на базовой карте**, потому что он сам по себе не кодирует родную принадлежность территории.

## Как пользоваться

1. `/demo` — загрузить встроенную карту войны Йогуртстана, старт `2057-01-01`
2. `/map` — получить **текущий** кадр
3. `/turn 60 110` — создать ход на 60 дней с базовой шириной наступления 110 px
4. Нарисовать линии **поверх свежего `/map`**:
   - `#FF00FF` — наступление Кефирстана
   - `#00FF66` — наступление Йогуртстана
5. Отправить PNG **как файл**
6. Повторять ходы
7. `/export 30 1920` — H.264 MP4, 30 fps, ширина до 1920 px

Линия может быть прямой, горизонтальной, вертикальной, диагональной, кривой, S-образной или ломаной. Можно рисовать несколько независимых линий одной стороны и линии обеих сторон одновременно.

## Как бот понимает линию

Наклон линии не используется как специальный признак. Движок:

- находит часть штриха, связанную с текущей территорией атакующего
- считает расстояние **вдоль самой линии**, поэтому кривая и горизонтальная линия работают так же, как вертикальная
- ищет первый выход в чужую или серую территорию
- строит вокруг линии неровный оперативный коридор
- не тратит половину срока на путь по собственному тылу, если штрих начат глубоко внутри своей территории
- не позволяет коридору перескакивать через нейтральную/морскую дыру

Если часть нарисованных линий не связана со своей территорией или вообще не выходит к противнику, бот сообщает об этом.

## Живой фронт

Продвижение не линейное. Для каждого хода генерируются:

- быстрые и медленные дни
- почти стоящие дни
- короткие периоды затухания
- крупные выступы и провалы
- средние локальные различия
- мелкая неровность линии фронта
- запаздывание флангов относительно оси наступления

При одинаковом seed история детерминирована. `/undo`, `/doctor` и экспорт переигрывают те же операции.

## Серая зона

Серая зона теперь считается **реальным пространственным поясом** от устойчиво контролируемой территории, а не «9 единицами прогресса».

По умолчанию на исходной карте ее глубина около **9 px**. Она не зависит от того, длится наступление 10 дней или 500 дней.

При уменьшении видео визуальная толщина пропорционально уменьшается вместе с картой.

## Встречные наступления

`/turn` рассчитывает обе стороны на одних и тех же датах.

Важно: план стороны включает не только чужую территорию, но и активную зону собственного фронта. Поэтому в длинном ходе возможна нормальная ситуация:

- Кефирстан занял участок на 30-й день
- Йогуртстанская контратака дошла туда на 47-й день
- участок снова меняет контроль или становится серым

Старый баг, при котором сторона не могла отбить землю, потому что в начале хода она еще считалась «своей», устранен.

## Защита от кривых входных данных

- приказ принимается только PNG-файлом
- размер должен совпадать с текущей картой
- бот сравнивает присланную карту с последним состоянием и отклоняет устаревший кадр
- базовая карта не может содержать серую зону без информации о homeland
- базовая карта может содержать оккупационные цвета, и бот правильно восстановит homeland/control
- нейтральные разрывы блокируют продвижение
- несколько одновременных сообщений одного чата защищены lock-ом
- запись операции транзакционная
- текущий control является кешем; журнал операций остается источником истины

`WIDTH` по умолчанию `110` px и задает базовую ширину оперативного коридора, не толщину серой зоны.

## /doctor

`/doctor` полностью переигрывает журнал операций и сравнивает результат с текущим кешем `current_control.npy`.

Если кеш разошелся после падения процесса или поврежденной записи, он автоматически восстанавливается из истории.

## Экспорт

Экспорт больше **не пересчитывает войну в уменьшенном разрешении**. Симуляция всегда идет в исходном разрешении карты. Для видео уменьшается уже готовый слой контроля.

Поэтому `/map`, replay, `/undo`, `/doctor` и MP4 используют одну и ту же геометрию фронта.

Видео содержит стартовый кадр плюс один кадр на каждый прошедший день. Например, операция на 30 дней дает 31 кадр вместе с исходным состоянием.

## Ограничения

- максимум 8192 px по стороне
- максимум 35 млн пикселей на изображение
- ход: 1-5000 дней
- базовая ширина операции из Telegram-команд: 8-800 px
- для точных цветов и проверки свежести кадра используй PNG как файл, не фото и не JPEG

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
export BOT_TOKEN='123456:token'
export OWNER_ID='123456789'      # рекомендуется для личного бота
python run.py
```

PowerShell:

```powershell
$env:BOT_TOKEN='123456:token'
$env:OWNER_ID='123456789'
python run.py
```
