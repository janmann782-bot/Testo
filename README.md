# Kefirstan VTuber Android

Aurelia VTuber application. The complete Android Studio project and user-provided 3D office scene are archived in `project-source.zip`.

The GitHub Actions workflow unpacks it and builds an Android debug APK. Download the APK from the latest successful workflow run's Artifacts panel.

Source GLB attribution and original files are inside the archive. This is an unsigned-for-release debug build, intended for manual installation and testing.
